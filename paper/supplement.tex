\paragraph*{Evidence labels, bars and design history.}
CONFIRMATORY means bars, cells, arms and code fixed in advance and scored on fresh data; CORRECTIVE REANALYSIS, a check named by a referee with the referee's criterion as the bar, on data already analysed; EXPLORATORY, everything else. Only gated statements had a bar, and the gates were written after an exploratory phase had shown the effects they test, so they confirm stability on fresh data and are not independent discoveries. The plan was committed before the first run, and each of the thirteen amendments and the later registrations before its run. A change is declared when the band for $d(t_j)-d(t_0)$ lies wholly beyond a $\pm0.25$ equivalence margin; this gives the false-positive rate (FPR) on controls and the \emph{power} on realised crossovers. The bar, fixed before any simulation and never changed, is: (C) pooled control coverage $\ge93\%$ with no cell's Clopper--Pearson (CP) upper bound below 93\%; (F) FPR $\le5\%$. The 93\% bar is a tolerance around a nominal 95\% procedure, not evidence of exact calibration, and pooled CP intervals are a binomial reference for a fixed mix of cells. The estimator set grew through the amendments in response to earlier results, the joint test was defined after the endpoint test had been seen on the same data, and family-wise error across all looks is not controlled. Checks registered and not run are listed in \texttt{REGISTERED\_NOT\_RUN.md} in the repository.

\paragraph*{Graphs, window and eligibility.}
Controls: rings $C_L$ ($L=128$--1024), 2D tori ($L=24$--96), 3D tori ($L=16$--32); they are near-constant over the reference windows defined by exact $Nq(t)\ge6$, and adaptive windows can extend beyond those. Crossovers: $C_L\times C_{16}$ ($L=32$--768) and $C_L\times C_8^2$ ($L=32$--256); $L$ sets how much of the one-dimensional regime the window reaches. Walkers are grouped into 200 blocks, the unit of a cluster bootstrap; each walker is one path through the grid times, so counts at different times are correlated. Split-sample estimators assign alternate blocks to halves A (selection) and B (inference). $J$ is the number of window points. The window-based estimators are defined only for $J\ge6$, a rule frozen before the first run, which we treat as an \emph{eligibility domain}: a dataset with $J<6$ is an abstention, and with windows fixed from the exact curve a cell whose exact window has fewer than six points is unanswered by rule at every budget. \MLP{} has no six-point rule: it needs two window times and uses every grid time as a constraint.

\paragraph*{Constructions.}
All fits are in $u=\ln t$ with $y=\ln\hat P$. Local-polynomial fits use a Gaussian kernel in $u$ multiplied by the return counts as weights, with no boundary correction beyond the polynomial order; the bandwidth is chosen by leave-one-out cross-validation on half A, from $\{0.5,0.7,1,1.4,2\}$ for local-linear and $\{0.7,1,1.4,2,2.8,4\}$ for local-quadratic fits. Half A fixes the window, the bandwidth and (for \textsf{BiasAware-CV} and \textsf{BiasAware-Rule}) the bound $M$; half B supplies the estimate and its bootstrap. The bootstrap resamples the 200 walker blocks ($B=200$ draws; 1000 for the \textsf{MonoLP} box); the split arms resample within the 100-block half used for inference. It re-runs the estimator on each draw, except that \textsf{BiasAware} holds the fitted weights fixed across the draws used to calibrate the band. The change band is built as in the main text for the contrasts $\Delta_j=d(t_j)-d(t_0)$, $j\ge1$, with its own maximum over $j$, so the search over tested times is inside the calibration. For \textsf{BiasAware} the weights $a^{(j)}$ at each window point minimise $1.96\sqrt{a^{\top}Sa}+(M/6)\sum_i|a_i||u_i-u_j|^3$ subject to annihilating constants and quadratics and reproducing the slope, with $S$ the bootstrap covariance of $y$ on half B; $M$ bounds $|d^3\ln q/du^3|$ on the window range; the band is $\hat\beta_j\pm(c\,\mathrm{sd}_j+B_j)$ with $B_j$ the worst-case bias term, and the change band uses $B_j+B_0$. \textsf{BiasAware-CV} takes $M$ as the largest $|6\times\text{cubic coefficient}|$ of a local-quartic fit on half A over the window points; \textsf{BiasAware-Rule} takes the largest third derivative of one weighted quartic fitted to the whole window.

\paragraph*{Zero-count floor.}
Every bootstrap-based arm floors each replicate of the return fraction at $0.5/W$ ($W$ the walkers in the half-sample) before the logarithm; how often the floor acts was not measured. \textsf{MonoLP} does not use $\ln P^*$; its box treats a zero count through a Clopper--Pearson limit.

\paragraph*{Truth and simulation law.}
The exact curves were recomputed independently in SageMath in 120-bit arithmetic (maximum deviation $1.4\times10^{-13}$ in $d$). Each walker is simulated as a single path and its return indicator is recorded at each grid time, so counts at different times are correlated as for the real walk. On the ring $C_{128}$ the exact covariance of one walker's return indicators at $t=24$ and 34 is $q(24)[q(10)-q(34)]=0.009142$; the simulation gave $0.009132$ (standard error $0.000013$).

\paragraph*{Computing environments.}\label{sup:env}
The exploratory comparison, the frozen replication and the first \textsf{MonoLP} run were simulated under NumPy 2.4.6; the outer bounds, the fixed-window run, the holdout, the regression arms, Amendment 13 and the checks of Secs.~\ref{sup:nodrop} and~\ref{sup:redteam} under the pinned NumPy 2.5.5 and SciPy 1.18.1. The two versions draw different binomial counts from the same seed in part of the datasets: of the 1030 seeds regenerated for the outer bounds, the window length equals that of the first environment in 752. Results from the two environments on the same seeds are therefore two Monte Carlo realisations.

\section{\textsf{MonoLP}: box, outer relaxation and verification}\label{sup:e7}
\paragraph*{Box and programme.}
\textsf{MonoLP} forms a simultaneous box for $q$ at the grid times and reports, at each window time, the smallest and largest $d(t)$ over all such measures consistent with the box. The box was designed at 97.5\% and is coded more conservatively. The bootstrap part (1000 draws) takes the 0.99375 quantile of the largest absolute studentised deviation over the times with at least 30 returns, a nominal error of 0.625\%. The remaining times share 1.25\% equally, each with a two-sided CP interval. The nominal total is 1.875\%. The set of times that receive a CP interval is read from the same data and the Bonferroni division treats it as fixed; the bootstrap part is nominal and not exact. The bootstrap critical value is about 3.5 standard deviations where a 95\% max-$t$ value would be about 3.0; we did not rerun \textsf{MonoLP} at 95\%. Each endpoint is a linear-fractional programme, solved as a linear programme (Charnes--Cooper) on a measure discretised to 400 atoms log-spaced in $s$ plus atoms at $s=0$ and $s=\infty$; the atoms are doubled until no endpoint moves by more than 0.005. The grid stops at $s=1$ and then jumps to $s=\infty$; mass at $s>1$ changes the data by at most $e^{-24}$ at $t\ge24$, and 60 extra atoms on $(1,30]$ changed no decision in 1280 paired datasets (Sec.~\ref{sup:redteam}). The band is scored at the sampled window times, a dataset with fewer than two gets no result, and the programme uses all grid times as constraints. No band is returned, and a miss counted, when the solver fails: all 66 such datasets were HiGHS status 4 (numerical difficulty), none infeasible. Of 9400 datasets at 32 walkers per node 66 have no band; all 44 misses on realised crossovers and four of the five on controls are of this kind. The joint test \textsf{MonoLP-Joint} takes the extremes of $d(t_j)-d(t_0)$ over the same set by branch and bound with tolerance 0.002 (distinct from the ball-arithmetic check of Sec.~\ref{sup:nodrop}).

\paragraph*{Coverage and status (EXPLORATORY at 32 walkers per node; a dataset with no band is a miss).}
\MLP{} covers 99.8\% (CP 99.6--99.9) on controls and 98.8\% (98.4--99.1) through realised crossovers, with no false declaration in 2800 control datasets. In 170 of the 9400 datasets feasibility changed when the atoms were doubled; counting every atom-sensitive dataset as a miss, coverage is 2783/2800 (99.4\%) on controls and 3471/3600 (96.4\%) on realised crossovers. In the confirmatory runs its gated control coverage held and its ungated crossover coverage stayed at 98.9\% or above (Table~\ref{tab:joint}). Three layers have different status: given the box, the discretisation gap can be closed by the outer relaxation below; the box has a nominal error of 1.875\%, and the coverage of the band at a nominal error of 5\% is unmeasured; the numerics are double precision, verified on a sample in exact rational arithmetic.

\paragraph*{Outer relaxation (CORRECTIVE REANALYSIS).}
The support of the measure, $s\in[0,\infty]$, is partitioned into the atom at $s=0$, 1597 geometric cells that tile $(0,1]$, the first of which reaches down to $s=0$, and a tail cell $[1,\infty]$. For mass $m_k$ on cell $k$, $q(t_j)$ and the numerator of $d(t_j)$ are enclosed between the sums of $m_k$ times the minimum and the maximum over the cell of $e^{-st_j}$ and of $se^{-st_j}$. The tail is enclosed in the same way and is not truncated: it adds at most $e^{-t_j}$ ($4\times10^{-11}$ at $t=24$) to the upper enclosure of $q$ and nothing to the lower. The constants are computed in 80-bit ball arithmetic and rounded outward, and the box constraints are relaxed separately at each time, so the feasible set contains every admissible continuous measure. The upper endpoint is the smaller of two linear programmes and the lower endpoint the larger. The joint test was implemented for relaxation B only, so its three powers are B-only results. The reanalysis took 1030 dataset identifiers chosen beforehand (the 170 atom-sensitive ones, one with a withheld joint decision, a seeded sample of 300 stable ones, and all 600 of the 3D cells $L=160$, 192 and 256) and regenerated them in the second environment. The outer band contains the exact curve in 1029 and does not exist in one; the discretised bands of the same realisations covered 1024 and did not exist in six, and the outer band contains the discretised one in all 1024. Control coverage is 112/112 (CP 96.8--100.0) with no false change (0/112, CP 0.0--3.2), and crossover coverage 760/761 (99.3--100.0), under both relaxations. The outer-bound joint test declares the 3D drop in 170 of 200 datasets at $L=160$ (85.0\%, CP 79.3--89.6), 186 at $L=192$ (93.0\%, 88.5--96.1) and 198 at $L=256$ (99.0\%, 96.4--99.9). At $L=160$ the bar of 0.8 passes on the point estimate only. The other 8370 datasets were not recomputed.

\paragraph*{Exact verification.}\label{sup:lp}
The programmes are solved by HiGHS in double precision, which leaves the solves themselves unverified. To check them, 44 of the 1030 datasets were selected by a rule and a seed committed before any was solved: all seven with a non-zero solver status in any column, eight random ones from each of the three 3D minimum-size cells, eight atom-sensitive ones, four stable ones and the one with the withheld decision. For each, every endpoint programme of relaxation B was rebuilt, 2016 in all, and solved by dual simplex, and the final basis was checked in exact rational arithmetic. All 2016 were verified to be optimal: 1646 at the solver's own basis, and 370 after exact rational pivots from a basis that was dual infeasible by less than the solver's tolerance of $10^{-7}$. For the one dataset without an outer band, the emptiness of the relaxed set was certified by a strictly positive exact optimum of a phase-one programme. Over all 570 drops declared by the joint test in the 1030 datasets (554 in the three 3D cells of 200 and 16 elsewhere) the smallest margin to the threshold is $2.4\times10^{-5}$, against a solver error of about $4\times10^{-7}$ in absolute terms. Unverified: the other 986 datasets; relaxation A; and the 370\,259 programmes of the \textsf{MonoLP-Joint} branch and bound, which are covered by the margin analysis and not one by one. We therefore describe the outer-bound results as verified on a sample and otherwise numerical.

\section{The global no-drop test}\label{sup:nodrop}
EXPLORATORY for the bootstrap box; CONFIRMATORY for the exact box (last paragraphs). The test, its grid, search, solver, outcomes, bars and predictions were registered in a file committed before any registered cell was run (\texttt{PREREG\_GLOBAL\_NODROP.md}); only a synthetic unit test of the solver preceded it. The minimum drop, the continuum certificate and its two ball rechecks (P8, P9) were registered in amendments of \texttt{PREREG\_REDTEAM\_FINAL.md} before their runs. No frozen file was edited.

\paragraph*{Null and admissible set.}
The admissible set is that of \textsf{MonoLP} and \textsf{MonoLP-Joint}: $q(t)=\sum_k w_k e^{-ts_k}$ with $w\ge0$, $\sum_k w_k=1$, mass at least $1/N$ at $s=0$, and $q$ inside the box at every grid time. With $a(t)=\sum_k w_k s_k e^{-ts_k}$, $d(t)=2t\,a(t)/q(t)$. The \emph{global no-drop null} is that some admissible measure has $d(t_j)\ge d(t_0)-0.25$ at every later window time $t_j$. The joint test declares a drop only if a single $t_j$ drops for all measures; under the global test the dropping time may depend on the measure, so for the ideal tests on one feasible set at one margin the global test declares whenever the joint test does. The implementation has a guard of 0.005 on the margin and can return INCONCLUSIVE, so this is a property of the ideal tests, checked on the data below.

\paragraph*{Endpoint and joint tests (bootstrap box).}
The endpoint test compares the \MLP{} band endpoints at two times. The joint test made no false declaration in 2800 control datasets; in 3D it has the powers of Sec.~\ref{sup:e7}, and in 2D it declared no drop at any size through $L=768$ (0 of 200 at each size).

\paragraph*{Search.}
For a fixed value $r$ of $d(t_0)$ the constraints $2t_0a(t_0)=r\,q(t_0)$ and $2t_ja(t_j)\ge(r-0.25)\,q(t_j)$ are linear in $w$, so the null is a one-parameter family of feasibility programmes. The range of $r$ is the \textsf{MonoLP} band at $t_0$, split into six intervals and refined by branch and bound (bisection, smallest interval $2\times10^{-4}$, at most 400 programmes per atom grid). On an interval $[r_a,r_b]$ an \emph{outer} programme imposes $d(t_0)\in[r_a,r_b]$ and $d(t_j)\ge r_a-0.25-0.005$ for all $j$; if it is infeasible, no admissible measure with $d(t_0)$ in that interval avoids a drop larger than 0.255. An \emph{inner} programme imposes $d(t_j)\ge r_b-0.25$; a measure that it returns is checked independently of the solver (weights on the simplex to $10^{-6}$, atom at zero, box to a relative $10^{-7}$, and the smallest change recomputed from the measure). The programmes are solved by HiGHS in double precision on 800 atoms.

\paragraph*{Outcomes.}
DROP: every interval is excluded and none is unresolved, on the 800-atom grid and again on a 1597-atom grid. WITNESS: a verified no-drop measure is returned. INCONCLUSIVE: an unresolved interval below the smallest width, the limit of 400 programmes, or a numerical solver status; a drop on the coarse grid that the fine grid does not repeat is also inconclusive. A box that no measure fits is counted separately and never as a drop; it did not occur. For each dataset a verified measure \emph{with} a drop larger than 0.25 was also sought; where both witnesses exist the box cannot decide.

\paragraph*{Exact returns (sign test).}
The registration required DROP on $C_{768}\times C_{16}$ with exact returns before any data run could be reported. \paragraph*{Continuum certificate (the 37 bootstrap-box declarations).}
For each interval of $r$ left by the search on the 800-atom grid, and for four pad intervals that extend the range of $r$ below and above the grid band so that measures off the grid are covered, an elastic phase-one programme gives multipliers whose dual function is $g(s)=v_1+\sum_j(P_j+Q_js)e^{-t_js}$. The interval is \emph{certified} if, after a shift of the multipliers, $g\ge0$ on the whole support with a strictly negative objective: on $(0,1]$ by interval branch and bound with a second-order centred enclosure, on $s\ge1$ by the bound $(|P_j|+|Q_j|)e^{-t_j}$, and at the atoms $s=0$ (with its $1/N$ floor) and $s=\infty$. A point where the check fails is added as an atom and the programme solved again (at most 12 rounds). Result: 37 certified, 0 not certified, 0 solver failures, over 485 intervals (10 to 29 per dataset), the 148 pad intervals among them. Sixteen datasets needed added atoms (619 in all, at most 148 in one). The cells tile the real line in $r$, two unbounded end cells included, and exact equality of the shared endpoints was asserted for all 37 datasets. Rechecks registered afterwards (P8, P9) recomputed $P_j$, $Q_j$ and the objective in 100-bit Arb balls from the raw multipliers, the box and the cell thresholds, and tested $g\ge0$ on the whole support: all 485 cells of the 37 datasets passed, with the largest upper bound of the objective $-2.2\times10^{-5}$. The multipliers themselves come from the floating-point LP. The registered falsifiers and sentinels behaved as required: a damaged constant or multiplier fails, a gap breaks the tiling, and nothing certifies around the stored measure of any of the 58 WITNESS datasets. The certificate concerns the decision given the stored box. It says nothing about the coverage of that box, which is nominal, and with the bootstrap box it was not applied to the 3D declarations or to $D_{\rm lo}$, which rest on finite atom grids. The full account is in \texttt{RESULTS\_MINDROP\_CERT.md} in the repository.

\section{Bias-aware bands: diagnoses and the split-covariance test}\label{sup:e4}
\paragraph*{Coverage, eligibility and status.}
\BA{} bands are fixed-length intervals in the manner of Refs.~\cite{ak2018,ak2020} for the slope under a bound $|d^3\ln P/du^3|\le M$ (Sec.~\ref{sup:bench}). At fixed windows \BAC{} covered 97.7\%, 97.0\% and 96.2\% of answered datasets at the three budgets (bar (B), 93\%), and in the holdout 98.7\%, 97.0\% and 97.8\% (gate, 90\%). The level has a price in power: at 128 walkers per node \BAC{} declared a drop in 69.3\% of answered datasets against 97.1\% for \LQ{} (ungated). These figures are conditional. Over all generated datasets \BAC{} stands at 86.8\%, 86.1\% and 85.3\% and bar (B) would fail; in the holdout the corresponding figures are 65.5\%, 77.4\% and 78.5\% and the gate would fail. Pooled figures also hide weak cells: at 128 walkers per node on the largest 3D graph \BAC{} covers 170 of 200 datasets. These are heuristic plug-in bands, not honest bands in the sense of Refs.~\cite{ak2018,ak2020}, whose results are for a known bound, and we claim no guarantee.

\paragraph*{Fitted bound and allowance (ungated).}
At fixed windows the fitted bound $M$ is below the fine-grid reference maximum in 17.3--43.7\% of datasets for \BAC{} and 25.3--53.0\% for \BAR{}; coverage is 87--94\% among those datasets and 99--100\% among the others. With the oracle bound the realised bias never exceeded half of the allowance. Together with the optimistic noise calibration of the oracle arm below, this is why the gated coverage is consistent with partially cancelling errors; it is an inference, not a measured decomposition.

\paragraph*{Oracle arm (EXPLORATORY).}
The oracle arm \textsf{BiasAware-Oracle}, whose $M$ is a fine-grid maximum computed from the exact spectrum (600 log-spaced points plus the observation times, with a $10^{-3}$ floor), failed the cell rule on the ring $L=512$ in the exploratory comparison. A diagnosis specified before it was run re-executed the frozen code on the four ring cells, on the original seeds and on 4000 fresh seeds per cell. No miss is a bound miss: in the 15\,125 answered datasets the exact bias never exceeded the allowance, and the largest ratio is 0.50. With 4000 datasets per cell the complete band covers 92.0--92.6\% in every ring cell, and the median bootstrap standard deviation is 83--95\% of the empirical standard deviation of the same quantity across datasets. The oracle arm is therefore not a 95\% reference on these cells; its shortfall is in the noise calibration.

\paragraph*{\textsf{BiasAware-Split} (Amendment 13(a); CONFIRMATORY).}\label{sup:a13}
\textsf{BiasAware-Split} computes the covariance $S$, and from it the weights $a^{(j)}$ and the standard deviations, from a 200-draw bootstrap of half A; half B supplies the point estimate and the max-$t$ critical value. The bias allowance is computed from the half-A weights and $M$, using the oracle value or the half-A fit. The bound $M$ is as in the original arm: the oracle value or the held-out fit (the CV form). All four arms were run on the same walkers, on the 14 control and 19 crossover cells of the replication design and on the 6 control and 10 crossover cells of the holdout design, at 8, 32 and 128 walkers per node, 200 datasets per cell, on fresh seeds. A variant is validated in a design if all three pass. Both variants were validated in both designs: over the two designs and three budgets their control coverage is 95.8--99.8\% and their crossover coverage 97.1--99.5\% (the full table is in \texttt{RESULTS\_AMEND13.md} in the repository). Three of four ungated predictions held; the fourth (half-width ratio) is in the stored report.

\paragraph*{Prior art for \textsf{MonoLP}.}\label{sup:prior}
We read the full texts of Lawrence \cite{lawrence2024}, Mutzel and Tilloy \cite{mutzel2026} and Lehner \cite{lehner2026}. Lawrence bounds integrals of a positive spectral density from noisy Euclidean correlators by convex optimisation over a Mahalanobis region with a bootstrap threshold at the 99\% level, solved by Lagrange duality. Mutzel and Tilloy replace his dual solver by a hierarchy of semidefinite programmes with rigorous bounds and add an infeasibility certificate that flags implausible data, the analogue of \textsf{MonoLP} returning no band when no measure fits the box. Lehner calibrates the interval with a $\Delta\chi^2$ threshold, separates a jackknife statistical error from a systematic part, and reports coverage tests on correlators, smeared densities and step functions. All three work with linear functionals, an ellipsoidal region and Gaussian errors. \textsf{MonoLP} differs in the target (a ratio of two linear functionals, by the Charnes--Cooper transformation), the region (a box from walker counts with Clopper--Pearson limits), the object (random walks on finite graphs) and the crossover tests built on the same set. Stark's strict bounds \cite{stark1992} are the earlier general construction; we cite them for that role and did not have access to the full text. The skeleton (a data-space region, positivity of the measure, an outer relaxation) is prior art, and we claim the application only; the global no-drop test of Sec.~\ref{sup:nodrop} is a feasibility question on the same set and is covered by the same statement.

\section{Regression standard errors under shared walkers}\label{sup:gk}
CONFIRMATORY. A pre-registered benchmark took the weighted log--log point fit of Ref.~\cite{gk2022} on our grid and window and varied only the standard error; nothing here bears on that work in its own setting. With the regression standard error the interval covers the exact value in 1716/1930 (88.9\%, CP 87.4--90.3) of answered control datasets at 32 walkers per node and misses bar (C); with a model-based error (93.9\%) or a walker-block bootstrap (93.6\%) it is met. A plausible reason, not isolated by the run, is that all time points come from the same walkers.

\section{Software and reproducibility}\label{sup:soft}
The simulations and analysis use Python with NumPy, SciPy (HiGHS for \textsf{MonoLP}), pandas and Matplotlib; the exact rational verification and the ball checks use python-flint (Arb) and highspy 1.16.0. As a reproducibility spot check, one small cell from each of the replication, outer-bound, fixed-window and holdout runs was re-run from the committed code in a fresh pinned environment (Python 3.12.3, NumPy 2.5.5, SciPy 1.18.1) and compared with the stored results: every discrete outcome matched; for \textsf{MonoLP} in the replication cell 51 continuous values differed between machines, traced to the walks (Sec.~\ref{sup:bench}). One cell per run does not show that all cells reproduce.

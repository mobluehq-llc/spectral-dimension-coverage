## Question and test
Per dataset: box (lo, hi) over the grid ts, window length Jw (the frozen window rule `L.window_len`; exact mode: the cell's `exact_J`). Admissible set = lazy-walk measures q(t) = sum_k w_k exp(-t s_k), w >= 0, sum w = 1, mass at s = 0 >= 1/N, lo <= q(ts) <= hi (identical to the E7/E7j set; atom grid `A8.atoms_grid(tmax, 799)`, gate 1597). **Global no-drop null:** some admissible measure has d(t_j) >= d(t_0) - 0.25 for EVERY j = 1..Jw-1 (d = 2 t a / q, a = sum w s e^{-ts}). The joint test declares a drop only if one single j drops for all measures; the global test is strictly stronger (the dropping j may depend on the measure).
- **Grid and r-search:** fixed grid ts = the cell's `ts_w`; r = d(t_0) searched over [d0min, d0max] (the E7 band of t_0 from `A8.lp_one`), split into 6 intervals, then rigorous branch and bound (FIFO, bisection, smallest interval 2e-4, cap 400 LPs per atom grid).
- **Solver:** scipy `linprog`, HiGHS (fallbacks highs-ipm, highs-ds), feasibility LPs in the Charnes-Cooper scaling of `A8.lp_setup` with tau fixed to 1 (y = w), 800 atoms (gate 1597).
  - OUTER LP on [ra, rb] (relaxation): d0 in [ra, rb] and d_j >= ra - 0.25 - 0.005 for all j >= 1. Infeasible => no no-drop measure with d0 in [ra, rb] even if drops up to 0.255 were tolerated (margin 0.005).
  - INNER LP (restriction): d_j >= rb - 0.25. A returned measure is **verified independently** (simplex within 1e-6, atom at 0 >= 1/N, box within relative 1e-7, actual min Delta computed from the measure >= -0.25 - 1e-9); an outer solution that passes the same verification is also accepted.
- **Outcomes:** WITNESS (a verified no-drop measure is returned; the global null is not excluded); DROP (all intervals excluded, none unresolved, AND the same holds on the 1597-atom grid; a drop on the coarse grid that the fine grid cannot repeat is reported as INCONCLUSIVE, a witness on the fine grid as WITNESS); INCONCLUSIVE (interval narrower than 2e-4 unresolved, LP cap, or numerical LP status); BOXINFEASIBLE (E7 band of t_0 infeasible: no measure fits the box; counted separately, NEVER as DROP); NOWINDOW (Jw < 2).
- **Witness-pair output:** per dataset the no-drop witness (r, min Delta, d trajectory string) and a verified DROP witness (admissible measure with a drop > 0.25 from t_0 to some t_j; restriction LP over 6 r-intervals, late j first). Both present = AMBIGUOUS in the SA2 sense: the box cannot decide.
- **Certification caveats (stated now):** DROP is certified up to LP floating tolerance with margin 0.005 and the 2x atom grid gate (continuum measures not on the grid are not covered rigorously); no exact rational audit of the final bases is done here.
